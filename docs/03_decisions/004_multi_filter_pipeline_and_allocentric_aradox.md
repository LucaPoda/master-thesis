# ADR 004: Multi-Filter Pipeline & The Allocentric Paradox

**Date:** 2026-10-02
**Status:** Accepted

## Context
To address the visual flickering (false negatives) and coordinate noise generated by the `NoisyPerceptionSystem`, we needed to stabilize the semantic graph's inputs. We implemented a comparative pipeline featuring four estimators:
1. **Exponential Moving Average (EMA):** A temporal smoother.
2. **Weighted Least Squares (WLS):** A static non-Bayesian estimator.
3. **Linear Kalman Filter (KF):** A dynamic Bayesian estimator.
4. **Extended Kalman Filter (EKF):** A dynamic non-linear Bayesian estimator.

Initial telemetry evaluations revealed an unexpected result: the WLS estimator significantly outperformed the EKF (RMSE of 0.090m vs 0.158m). 

Analysis of estimation theory highlighted an architectural shortcut in our simulation. The current `NoisyPerceptionSystem` outputs absolute allocentric coordinates perturbed by zero-mean Gaussian noise. For perfectly static parameters (like world landmarks in absolute coordinates), WLS acts as the Minimum Variance Unbiased Estimator (MVUE). It acts as an optimal low-pass filter, shrinking the covariance matrix iteratively. Conversely, the KF and EKF constantly inject process noise ($Q$) during their prediction steps, assuming dynamic movement. This forces the Bayesian filters to rely too heavily on the noisy measurement matrix ($R$), preventing convergence.

## Decision
1. Retain the multi-filter pipeline (EMA, WLS, KF, EKF) for comparative logging and evaluation.
2. Immediately refactor the `NoisyPerceptionSystem` to output **egocentric relative vectors** (euclidean distance, yaw, pitch) rather than absolute world coordinates.
3. Update the Extended Kalman Filter to utilize the non-linear Jacobian required to fuse these egocentric measurements with the agent's drifting odometry.
4. Tune the process noise matrix ($Q$) strictly: high for the ego-state (robot pose) and near-zero for the mapped landmarks.

## Consequences
*   **Pros:** Forces the system to solve a mathematically authentic SLAM problem. The egocentric shift will naturally break the WLS estimator's effectiveness (as the robot's pose drift introduces non-Gaussian distortion), allowing the EKF to demonstrate its intended capability in fusing drifting odometry with local vision.
*   **Cons:** Increases mathematical complexity. Computing the Jacobian matrices for 3D range/bearing to Cartesian mappings requires careful implementation to avoid filter divergence.
